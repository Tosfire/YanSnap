# YanSnap 测试指南

本文面向贡献者和发布维护者，说明自动测试、交互测试和发布前兼容性检查。

## 自动测试

配置并构建 Release：

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

CTest 当前覆盖：

| 测试 | 范围 |
| --- | --- |
| `GeometryTests` | 负坐标、选区裁剪、边界移动 |
| `SettingsTests` | 默认值、单键和组合快捷键解析 |
| `AnnotationTests` | 标注合成、撤销/重做、马赛克和 PNG 编码 |

`OcrIntegration` 使用 GDI 生成同时包含中文、英文、数字和 URL 的测试图像，再调用正式版相同的 Windows OCR 路径。它属于系统集成测试，需要本机安装中文 OCR 语言功能，因此不加入默认 CTest。

自动测试必须在提交前全部通过。

## 交互测试程序

交互测试默认参与构建，但不会由 CTest 自动启动，以免在无人值守环境中控制桌面或剪贴板。

可通过以下选项明确启用：

```powershell
cmake -S . -B build -A x64 -DYANSNAP_BUILD_INTEGRATION_TESTS=ON
cmake --build build --config Release
```

主要程序：

| 程序 | 用途 |
| --- | --- |
| `StartupIntegration` | 后台启动、重复启动和单实例 |
| `OverlayIntegration` | 自由选区、复制和自动保存 |
| `WindowSelectionIntegration` | 窗口识别与 DWM 边界 |
| `OverlayPinIntegration` | 当前选区贴图回调 |
| `PinWindowIntegration` | 剪贴板读写、贴图缩放与显隐 |
| `SettingsPreview` | 设置窗口渲染检查 |
| `UiPreview` | 工具栏悬停、提示和视觉布局 |
| `OcrIntegration` | 中文、英文、数字和 URL 的本地 OCR |

运行交互测试前请关闭正式 YanSnap 进程，避免全局快捷键和单实例互相影响。

## Pull Request 最低检查

- [ ] Release x64 编译成功
- [ ] CTest 全部通过
- [ ] 启动后只驻留托盘，不立即截图
- [ ] 默认 `F1` 可进入截图
- [ ] 复制与 PNG 保存成功
- [ ] 退出后没有残留进程
- [ ] 新增界面在 100% 和 150% DPI 下没有裁切
- [ ] 用户可见行为已经更新 README 或用户指南

## 截图与标注检查

- [ ] 自由拖选输出尺寸与选区标签一致
- [ ] 单击高亮窗口后，输出尺寸与 DWM 边界一致
- [ ] 八个控制点和选区拖动正常
- [ ] 工具栏悬停状态、手形光标和中文提示正常
- [ ] 矩形、箭头和画笔预览与最终图片一致
- [ ] 中文文字输入、换行、粘贴和取消正常
- [ ] 马赛克实际破坏原始细节
- [ ] 撤销、重做和删除顺序正确
- [ ] 保存失败或剪贴板占用时不会丢失当前截图

## 文字识别检查

- [ ] 截图工具栏显示 OCR，悬停提示包含 `Ctrl+R`
- [ ] 点击 OCR 后仍停留在当前截图遮罩，不创建独立顶层窗口
- [ ] 识别卡片优先放在选区旁，并保持在桌面可见区域
- [ ] 中文、英文、数字和 URL 可同时识别
- [ ] 结果可编辑，`Ctrl+A`、`Ctrl+C` 和“复制全部”可用
- [ ] “返回截图”或 `Esc` 可关闭识别卡片并继续截图
- [ ] 未安装语言包、空结果和识别失败都有明确提示
- [ ] OCR 期间界面不阻塞，关闭截图后没有残留线程或进程

## 贴图检查

- [ ] `Ctrl+T` 可将当前选区贴到屏幕
- [ ] `F3` 可读取剪贴板图片
- [ ] 贴图保持置顶并可拖动
- [ ] 滚轮缩放保持光标锚点
- [ ] `Ctrl+滚轮` 可调透明度
- [ ] 显示、隐藏、复制、保存和关闭菜单正常
- [ ] 新截图不会把现有贴图重复截入

## 设置检查

- [ ] 快捷键输入框识别实际按下的单键或组合键
- [ ] 快捷键冲突时恢复旧值
- [ ] 配置写入后重启可恢复
- [ ] 损坏配置会备份并回退默认值
- [ ] `portable.flag` 存在时配置保存在 EXE 同目录
- [ ] 启用开机自动启动后，当前用户启动项指向正确 EXE
- [ ] 取消开机自动启动后，对应启动项被删除

测试注册表启动项后应恢复测试前状态。

## 兼容性矩阵

正式 Release 建议覆盖：

| 环境 | 必测内容 |
| --- | --- |
| Windows 10 22H2 x64 | 启动、截图、保存、托盘 |
| Windows 11 x64 | 启动、截图、保存、托盘 |
| 1920×1080，100% DPI | 完整功能回归 |
| 4K，150% / 200% DPI | 设置窗口、工具栏和贴图尺寸 |
| 混合 DPI 双屏 | 窗口识别、选区移动和跨屏截图 |
| 副屏位于左侧或上方 | 负坐标几何 |
| 横屏与竖屏混合 | 遮罩覆盖和工具栏定位 |

无法覆盖的组合应在 PR 或 Release Notes 中明确记录，不应伪装为已验证。

## 隐私检查

- [ ] 主程序不新增网络客户端依赖
- [ ] 不记录截图像素、剪贴板内容或敏感路径
- [ ] 不添加账号、遥测、广告或隐式上传
- [ ] 开机启动仅在用户主动启用时写入当前用户注册表
- [ ] 发布包不包含开发机配置、构建缓存或测试截图
