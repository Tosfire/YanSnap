## 构建与进程

- [x] Visual Studio Build Tools 2022 17.14 + MSVC 14.44 + CMake 4.4 的 Release x64 可编译，生成单个 `YanSnap.exe`
- [x] 连续启动两次只有一个进程
- [x] 首次及重复双击 EXE 均只驻留后台并显示通知，不自动打开截图遮罩
- [x] 托盘悬停显示 `YanSnap`、当前截图快捷键和 `F3` 贴图快捷键
- [x] 通知标题和正文使用 Unicode 中文，无乱码
- [x] 正常关闭后无残留进程
- [x] 静态链接编译器运行库，无第三方 DLL
- [x] 导入表没有 WinHTTP、WinINet、Winsock 等网络组件
- [x] EXE 嵌入 YanSnap 多尺寸图标，资源管理器、窗口和托盘使用同一图标
- [x] 便携 ZIP 解压后无需安装或管理员权限即可运行
- [x] `portable.flag` 存在时设置写入 EXE 同目录 `config.ini`
