# YanSnap 用户指南

本指南适用于从 GitHub Releases 下载的 YanSnap 便携版。

## 下载与启动

1. 打开 [YanSnap Releases](https://github.com/Li2190158085/YanSnap/releases/latest)。
2. 下载文件名类似 `YanSnap-1.1.0-win-x64-portable.zip` 的压缩包。
3. 将 ZIP 完整解压到一个可长期保留的目录。
4. 双击 `YanSnap.exe`。

YanSnap 启动后驻留在系统托盘，并显示“已在后台运行”通知。启动程序本身不会立刻截图。

如果 Windows SmartScreen 显示“未知发布者”，请确认文件来自本项目的官方 Releases 页面。YanSnap 当前没有商业代码签名证书，因此首次运行可能出现该提示。

## 系统托盘

鼠标悬停在托盘图标上会显示 YanSnap 名称和当前快捷键。右键托盘图标可使用：

- 截图
- 将剪贴板图片贴到屏幕
- 显示或隐藏全部贴图
- 关闭全部贴图
- 打开截图保存目录
- 设置
- 关于
- 退出

如果图标没有直接显示，请展开 Windows 通知区域中的隐藏图标。

## 截图

按 `F1` 或在托盘菜单中选择“截图”。

### 选择区域

- 按住鼠标左键拖动：创建自由选区
- 移动鼠标但尚未拖动：识别并高亮光标下的窗口
- 单击高亮窗口：选择该窗口
- 拖动选区内部：移动选区
- 拖动边框或控制点：调整大小
- 方向键：移动 1 个物理像素
- `Shift` + 方向键：移动 10 个物理像素

选区旁会显示尺寸和工具栏。靠近屏幕边缘时，工具栏和放大镜会自动调整位置。

### 标注工具

| 工具 | 用途 |
| --- | --- |
| 矩形 | 框出需要强调的区域 |
| 箭头 | 指向按钮、文字或位置 |
| 画笔 | 自由绘制 |
| 文字 | 添加中文或其他 Unicode 文字 |
| 马赛克 | 以实际像素块遮挡内容 |
| 撤销 / 重做 | 回退或恢复标注操作 |
| OCR | 在当前截图内识别选区文字 |
| 保存 | 选择路径保存 PNG |
| 复制 | 复制到剪贴板并结束截图 |
| 贴图 | 将当前选区作为置顶图片保留 |

文字工具支持系统中文输入法、换行和粘贴。使用 `Ctrl+Enter` 提交文字，使用 `Esc` 取消当前文字输入。

### 完成截图

- `Enter` 或 `Ctrl+C`：复制到剪贴板并完成
- `Ctrl+S`：选择路径保存 PNG
- `Ctrl+T`：贴到屏幕
- `Ctrl+R`：识别当前选区文字
- `Esc`：先取消当前编辑状态，再退出截图

如果在设置中选择“复制并自动保存”，复制完成后还会在默认保存目录生成 PNG 文件。

## 文字识别

建立选区后，点击工具栏中的 `OCR`，或按 `Ctrl+R`。YanSnap 不会结束本次截图，而是在截图遮罩内显示文字识别卡片。

- 支持中文、英文、数字、常见符号和 URL
- 识别结果可以直接编辑
- 按 `Ctrl+A` 全选、`Ctrl+C` 复制选中文字
- 点击“复制全部”可将全部结果写入剪贴板
- 点击“返回截图”或按 `Esc` 可关闭识别卡片并继续截图

OCR 只读取当前选区的原始截图，不会把矩形、箭头、文字或马赛克标注当作待识别内容。识别通过 Windows 本地 OCR 组件完成，不会上传截图或结果。

YanSnap 会优先使用已安装的中文 OCR 语言，并在不可用时尝试当前系统语言或英文。可识别语言取决于 Windows 已安装的“光学字符识别”语言功能。

## 贴图

有两种创建贴图的方式：

- 截图时点击工具栏中的“贴到屏幕”，或按 `Ctrl+T`
- 将图片复制到剪贴板后按 `F3`

贴图操作：

| 操作 | 结果 |
| --- | --- |
| 左键拖动 | 移动贴图 |
| 鼠标滚轮 | 缩放贴图 |
| `Ctrl` + 鼠标滚轮 | 调整透明度 |
| 双击 | 隐藏贴图 |
| 右键 | 打开复制、保存、比例、透明度和关闭菜单 |

开始新截图时，现有贴图会暂时隐藏，避免被重复截入。

## 设置

从托盘菜单打开“设置”。

### 截图快捷键

点击快捷键输入框后，直接按下需要的单键或组合键，不需要输入文字。默认值为 `F1`。

如果快捷键已被其他程序占用，YanSnap 会保留原快捷键并提示更换。

### 完成动作

- 仅复制：完成后只写入剪贴板
- 复制并自动保存：同时保存到默认目录

### 保存位置

默认目录为 Windows“图片”目录下的 `Screenshots`。自动文件名格式为：

```text
Screenshot_yyyyMMdd_HHmmss.png
```

同一秒出现重名时会自动追加 `_2`、`_3` 等序号，不会覆盖已有文件。

### 其他选项

- 成功后通知
- 截图中包含鼠标指针
- 开机自动启动

“开机自动启动”仅在用户勾选并保存后生效，不需要管理员权限。取消勾选并保存会移除启动项。

## 便携设置

官方便携包包含 `portable.flag`，因此配置保存在 YanSnap 目录中的：

```text
config.ini
```

移动整个解压目录即可迁移程序和设置。如果已启用开机自动启动，移动后请手动启动一次 YanSnap，程序会更新启动路径。

没有 `portable.flag` 时，配置位置为：

```text
%LocalAppData%\YanSnap\settings.ini
```

## 卸载

1. 如果启用了开机自动启动，先在设置中取消勾选并保存。
2. 右键托盘图标并选择“退出”。
3. 删除 YanSnap 的解压目录。

YanSnap 没有安装器、Windows 服务或驱动。

## 常见问题

### 按 F1 没有反应

快捷键可能被其他程序占用。右键托盘图标打开“设置”，录入新的快捷键并保存。

### 找不到托盘图标

展开 Windows 通知区域的隐藏图标；也可以再次运行 `YanSnap.exe`，已有实例会显示后台运行通知。

### F3 提示剪贴板没有图片

请先在其他程序中复制一张图片。仅复制文件路径或网页链接不会产生可贴图的位图。

### 保存失败

确认目标目录存在且当前用户有写入权限，然后重新选择保存位置。保存失败时 YanSnap 会保留当前截图。

### OCR 提示没有可用语言包

在 Windows“语言和区域”设置中，为中文或英文安装“光学字符识别”语言功能，然后重新启动 YanSnap。

### 截图出现黑色区域

DRM 内容、UAC 安全桌面和部分独占全屏程序无法由普通桌面捕获方式正常截图。

### HDR 画面颜色不一致

YanSnap 当前使用 Windows GDI 获取桌面，HDR 桌面可能出现亮度或色彩差异。
