YanSnap 便携版
================

使用方法
1. 请先完整解压 ZIP，不要直接在压缩包中运行。
2. 双击 YanSnap.exe。
3. 程序会驻留在系统托盘，不会在启动时自动截屏。
4. 默认按 F1 截图，按 F3 将剪贴板图片贴到屏幕。
5. 右键托盘图标可打开截图、贴图、设置和退出菜单。

便携模式
- 本目录中的 portable.flag 会启用便携模式。
- 设置保存在本目录的 config.ini。
- 截图默认保存在 Windows“图片\Screenshots”目录，可在设置中修改。
- 程序无需安装、无需管理员权限。
- 如在设置中勾选“开机自动启动”，程序只会写入当前用户的 Windows
  登录启动项；取消勾选会移除该启动项。
- 移动整个目录即可迁移程序和设置。

卸载
如果启用了“开机自动启动”，请先在设置中取消勾选并保存。
然后从托盘退出 YanSnap，删除整个目录即可。
