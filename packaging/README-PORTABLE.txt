YanSnap 便携版
===============

YanSnap 是一款轻量、便携、纯本地的 Windows 截图与贴图工具。
无需安装或登录，完整解压后即可运行。

官方网站
https://github.com/Li2190158085/YanSnap


开始使用
--------

1. 请先完整解压 ZIP，不要直接在压缩包预览窗口中运行。
2. 双击 YanSnap.exe。
3. 程序会驻留在系统托盘，不会在启动时立即截图。
4. 按 F1 开始截图；也可以右键托盘图标选择“截图”。

如果 Windows SmartScreen 显示“未知发布者”，请确认本程序来自上述
GitHub 官方仓库。YanSnap 当前没有商业代码签名证书，因此首次运行时
可能出现该系统提示。


常用快捷键
----------

F1                  开始截图，可在设置中修改
F3                  将剪贴板图片贴到屏幕
Enter / Ctrl+C      复制当前选区并完成
Ctrl+S              保存为 PNG
Ctrl+T              将当前选区贴到屏幕
Ctrl+R              在当前截图内识别选区文字
Ctrl+Z / Ctrl+Y     撤销 / 重做
Delete              删除当前标注
Esc                 取消当前操作或退出截图
方向键              移动选区 1 个像素
Shift+方向键        移动选区 10 个像素


截图
----

- 拖动鼠标可选择任意区域。
- 尚未拖动时，单击高亮窗口可快速选择窗口。
- 选区建立后可移动、缩放，并使用矩形、箭头、画笔、文字和马赛克。
- 按 Enter 复制，按 Ctrl+S 保存，按 Ctrl+T 贴到屏幕。
- 点击工具栏 OCR 或按 Ctrl+R，可直接在截图界面识别并复制文字。


文字识别
--------

- 支持中文、英文、数字、常见符号和 URL。
- 结果直接显示在截图遮罩内，不会单独打开应用窗口。
- 结果可以编辑；Ctrl+A 全选，Ctrl+C 复制，也可点击“复制全部”。
- 点击“返回截图”或按 Esc 可继续原来的截图操作。
- OCR 使用 Windows 本地语言组件，不上传截图或识别结果。


贴图
----

- 截图时选择“贴到屏幕”，或复制图片后按 F3。
- 左键拖动可移动贴图。
- 鼠标滚轮可缩放。
- Ctrl+鼠标滚轮可调整透明度。
- 双击可隐藏，右键可复制、保存、恢复比例或关闭。


系统托盘与设置
--------------

YanSnap 会持续驻留在 Windows 系统托盘。右键托盘图标可以截图、
管理贴图、打开保存目录、进入设置或退出程序。

设置支持：

- 修改截图快捷键
- 选择“仅复制”或“复制并自动保存”
- 修改默认保存目录
- 开关成功通知
- 选择是否包含鼠标指针
- 选择是否随 Windows 登录自动启动

快捷键设置框会识别你实际按下的单键或组合键，不需要输入文字。


便携模式
--------

本目录中的 portable.flag 会启用便携模式，设置保存在同目录的
config.ini。移动整个目录即可迁移程序和设置。

截图默认保存在 Windows“图片\Screenshots”目录，也可以在设置中修改。

如果已经启用开机自动启动，移动程序目录后请手动启动一次 YanSnap，
程序会更新 Windows 启动项中的路径。


隐私
----

YanSnap 不需要账号，不上传截图或 OCR 结果，不收集遥测，不保存截图历史，
也不包含广告或自动更新。截图和图像编码均在本机完成。

只有在用户主动启用“开机自动启动”时，程序才会写入当前用户的
Windows 登录启动项；取消该选项会移除启动项。


卸载
----

1. 如果启用了开机自动启动，请先在设置中取消勾选并保存。
2. 右键系统托盘图标，选择“退出”。
3. 删除整个 YanSnap 文件夹。

YanSnap 不会安装 Windows 服务或驱动。
